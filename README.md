# D-Plan: Empathetic Soft Paywall Prototype

Bu proje, yapay zeka destekli günlük planlama uygulaması **D-Plan** vaka çalışması için hazırlanmış çalışan bir Flutter mikro prototipidir. 

Kullanıcı kayıt olur olmaz çıkan doğrudan fiyat odaklı sert ödeme duvarı yerine, kullanıcının zihinsel yükünü hafifletmeyi vadeden ve şeffaf deneme takvimi sunan bir ödeme akışı simüle edilmiştir.

### Nasıl Çalıştırılır?
1. `lib/main.dart` dosyasındaki kodu kopyalayın.
2. [DartPad](https://dartpad.dev) sitesine gidin.
3. Sol üstten ortamı **Flutter** olarak seçip kodu yapıştırın ve **Run** butonuna basın.
4. "3 Gün Zihnini Rahatlat (Bugün 0 TL)" butonuna tıklayarak açılan şeffaf deneme modalını test edebilirsiniz.
